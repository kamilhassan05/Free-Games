Put these 5 files in this folder:
  bootloader.bin
  partitions.bin
  boot_app0.bin
  firmware.bin
  spiffs.bin   (your data/ folder: index.html + games/)

The offsets in ../../manifests/esp32-s3.json must match your partition table.
Check them with:  pio run -e <env> -t upload -v   and   pio run -e <env> -t uploadfs -v
(Manifest offsets are DECIMAL: 0x1000 = 4096, 0x8000 = 32768, 0xe000 = 57344, 0x10000 = 65536, 0x290000 = 2686976.)
