The WROOM-32U is tested. The DevKit V1 uses the same chip and firmware but hasn't been tried yet. Other boards will be enabled after real-hardware testing.

How to Flash

  • 1
    Install USB Drivers Most systems detect ESP32 automatically. If not, install the CP210x or CH340 driver.
  • 2
    Enter Bootloader Mode Hold BOOT, press RESET once, then release BOOT. The board is now in flash mode.
  • 3
    Connect via USB Plug your ESP32 into your computer using a data-capable USB cable (not a charge-only cable).
  • 4
    Click "Flash Firmware" Select the correct COM port in the browser dialog, then click Install. Wait for the process to complete.
  • 5
    Press Reset After flashing completes, press RESET. Connect to the Wi-Fi named Free Games (no password) and open http://192.168.4.1.
⚠️
Before you flash Flashing will erase existing firmware on the device. Make sure you are using a data USB cable, not a charge-only cable. If the port does not appear in the browser dialog, try a different cable or USB port.

Troubleshooting

  • No serial port appears in browser dialog Use a data USB cable. Try a different port. Install the correct USB driver (CP210x or CH340). On Windows, check Device Manager.
  • Failed to download manifest Verify manifests/esp32-wroom-32u.json exists. Check GitHub Pages is enabled. Open the manifest URL directly in browser to confirm it loads.
  • Flashing fails or times out Hold BOOT, press RESET, release BOOT to enter bootloader mode manually, then retry.
  • GitHub Pages 404 on firmware files Confirm factory.bin is at firmware/esp32-wroom-32u/factory.bin. Paths in the manifest must match exactly (case-sensitive).
  • Page loads but button does nothing You are not using a supported browser. Switch to Chrome or Edge on a desktop computer.
  • Board boots but no Wi-Fi page Connect to the board's Wi-Fi (Free Games) and open http://192.168.4.1. If nothing loads, re-flash and press RESET once.
